# מה מוקרן? – לוח סרטים נגיש לאמא

דף אחד, באותיות גדולות, עם ההקרנות של השבוע הקרוב בסינמטק תל אביב ובקולנוע לב.
הדף מתעדכן לבד פעמיים ביום דרך GitHub, בחינם.

## הקמה (פעם אחת, בערך 15 דקות)

1. **פותחים חשבון** ב־github.com (אם אין לך).
2. **יוצרים מאגר חדש:** לוחצים על ה־`+` למעלה ← `New repository`.
   שם לדוגמה: `cinema-mom`. בוחרים **Public** (GitHub Pages בחינם דורש מאגר ציבורי).
   לוחצים `Create repository`.
3. **מעלים את הקבצים:** בעמוד המאגר החדש לוחצים `uploading an existing file`,
   גוררים את **כל** תוכן התיקייה (כולל התיקייה `.github`) ולוחצים `Commit changes`.
   > אם התיקייה `.github` לא עולה בגרירה (היא "מוסתרת"): לוחצים `Add file` ← `Create new file`,
   > כותבים בשם הקובץ `.github/workflows/update.yml`, מדביקים את תוכן הקובץ ושומרים.
4. **מפעילים את האתר:** `Settings` ← `Pages` ← תחת **Source** בוחרים `GitHub Actions`.
5. **הרצה ראשונה:** לשונית `Actions` ← `עדכון לוח הסרטים` ← `Run workflow`.
   אחרי דקה-שתיים יופיע וי ירוק. הכתובת של הדף תופיע ב־`Settings` ← `Pages`,
   בערך כך: `https://<שם-המשתמש>.github.io/cinema-mom/`

## בטלפון של אמא

- **אייפון:** פותחים את הכתובת ב־Safari ← כפתור השיתוף ← "הוסף למסך הבית".
- **אנדרואיד:** פותחים ב־Chrome ← שלוש הנקודות ← "הוספה למסך הבית".

מעכשיו יש לה אייקון "סרטים" שנפתח ישר ללוח.

## אם משהו מפסיק לעבוד

- GitHub שולח לך מייל כשהרצה נכשלת (למשל אם הסינמטק שינה את מבנה האתר).
- בלשונית `Actions` אפשר לראות את הפלט של כל הרצה – כמה הקרנות נמצאו בכל יום.
- לתיקון: שולחים ל־Claude את הקובץ `build.py` יחד עם עמוד השמור מהאתר (Ctrl+S בדפדפן).

## הגדרות (בראש הקובץ build.py)

- `DAYS_AHEAD` – כמה ימים להציג (ברירת מחדל 7).
- `HIDE_FAMILY_SCREENINGS` – לשנות ל־`True` כדי להסתיר הקרנות ילדים ומדובבות.

## הערות

- המאגר ציבורי, כלומר הקוד גלוי. אין בו שום מידע אישי. הדף מסומן כך שמנועי חיפוש לא יציגו אותו.
- GitHub משבית הרצות מתוזמנות במאגר שלא היה בו שינוי 60 יום. אם זה קורה, תקבל מייל,
  ומספיק ללחוץ שם על "Enable workflow".
